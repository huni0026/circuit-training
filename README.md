# 서킷 트레이닝 운동 타이머

Windows PC에서 서버를 켜고, 같은 와이파이의 태블릿 브라우저로 접속해서 쓰는 운동 타이머입니다.
리눅스, WSL, Docker, Python, Node.js 등 **추가 설치가 필요 없습니다** (Windows 기본 PowerShell만 사용).

## 사용 방법

| 파일 | 하는 일 |
|---|---|
| `서버시작.bat` | 서버를 켭니다. 서버는 작업 표시줄에 최소화된 창으로 실행되고, 태블릿 접속 주소를 보여줍니다. 이미 켜져 있으면 주소만 보여줍니다. |
| `서버중지.bat` | 서버를 끕니다. |
| `서버상태.bat` | 서버가 켜져 있는지, 접속 주소, 데이터 파일 위치를 보여줍니다. |

1. `서버시작.bat` 더블클릭
2. 표시된 주소(예: `http://192.168.100.5:8080`)를 태블릿 브라우저에 입력
3. 운동 끝나면 `서버중지.bat` 더블클릭

- `서버시작.bat` 창은 닫아도 서버가 계속 켜져 있습니다.
- 작업 표시줄의 **서버 창**을 닫으면 서버가 꺼집니다.
- PC에서는 `http://localhost:8080` 으로 같은 화면을 쓸 수 있습니다.
- 태블릿 브라우저 메뉴의 **홈 화면에 추가**를 하면 앱처럼 아이콘으로 실행할 수 있습니다.
- PC의 IP 주소는 공유기가 바꿀 수 있습니다. 접속이 안 되면 `서버상태.bat` 으로 주소를 다시 확인하세요.

## 처음 한 번만: 태블릿에서 접속이 안 될 때

Windows 방화벽이 태블릿 접속을 막고 있는 경우입니다.

1. **방화벽 허용 창**: 서버를 처음 켤 때 "Windows 보안 경고" 창이 뜨면 **개인 네트워크**에 체크하고 허용을 누릅니다.
2. **네트워크를 '개인'으로**: `설정 → 네트워크 및 인터넷 → Wi-Fi(또는 이더넷) → 연결된 네트워크 속성 → 네트워크 프로필 유형: 개인 네트워크`.
   집 와이파이가 "공용"으로 되어 있으면 방화벽이 접속을 막습니다. (`서버상태.bat` 에 "공용" 경고가 나오면 이 경우입니다.)
3. 그래도 안 되면 **관리자 권한 PowerShell**에서 아래 명령을 한 번 실행합니다 (개인 네트워크에서 8080 포트만 허용).

```powershell
netsh advfirewall firewall add rule name="Circuit Training 8080" dir=in action=allow protocol=TCP localport=8080 profile=private
```

## 데이터 (파일 DB)

- 설정과 운동 기록은 `data\circuit-data.json` 파일에 저장됩니다. DB 프로그램은 필요 없습니다.
- 직전 저장본은 `data\circuit-data.json.bak` 로 자동 보관됩니다.
- 백업은 `data\circuit-data.json` 파일을 복사해 두면 됩니다. 설정 화면의 **JSON 내보내기 / 불러오기** 로도 백업·복원할 수 있습니다.
- 서버가 꺼져 있을 때 바꾼 설정은 태블릿에 임시 저장되었다가, 서버가 다시 켜지면 자동으로 PC 파일에 저장됩니다.

## 운동 구성

- 운동 순서: 준비운동 → [동작 → 전환 → 동작 → … ] → 바퀴 휴식 → … (설정한 바퀴 수만큼) → 마무리
- 설정 화면에서 준비운동 시간, 각 동작 시간, 동작 전환 시간, 바퀴 수, 바퀴 사이 휴식, 마무리 시간, 토요일 회복 시간을 바꿀 수 있고 전체 시간이 바로 계산됩니다.
- 시작 화면에서 동작 체크를 해제하면 그날만 빠집니다.
- 요일별 동작 이름과 팁은 `public\schedule.js` 에서 바꿀 수 있습니다. 바꾼 뒤 태블릿 화면을 새로고침하세요.

## 예시 영상

- 시작 화면에서 각 동작 옆 **▶ 영상** 버튼을 누르면 유튜브 예시 영상 2~3개와 **유튜브에서 더 찾기** 검색 링크가 나옵니다.
- 준비운동·마무리 동작 이름을 누르면 유튜브 검색 결과로 연결됩니다.
- 영상은 유튜브에서 열리므로 영상을 볼 때만 인터넷이 필요합니다. 타이머는 인터넷 없이도 동작합니다.
- 영상 목록은 `public\schedule.js` 아래쪽 `VIDEOS` 에 있습니다. 영상이 삭제되었거나 다른 영상으로 바꾸고 싶으면
  `['영상ID', '제목', '채널', '길이']` 줄을 수정하세요. (영상ID = `https://www.youtube.com/watch?v=` 뒤의 11자리)

## 태블릿 사용 팁

- **소리**: '운동 시작'을 누른 뒤부터 효과음과 음성 안내가 나옵니다. 태블릿이 무음 모드면 소리가 나지 않습니다. 설정의 '소리 테스트'로 확인하세요.
- **화면 꺼짐**: `http://` 주소로 접속하면 브라우저의 화면 꺼짐 방지 기능을 쓸 수 없어서, 운동 중에 보이지 않는 영상을 재생하는 방식으로 화면을 켜 둡니다. 기기에 따라 동작하지 않을 수 있으니, 꺼지면 태블릿 설정에서 **화면 자동 꺼짐 시간**을 10분 이상으로 늘려 주세요.
- 타이머 화면 조작: 가운데 버튼 = 일시정지/계속, ◀ 이전 / 다음 ▶ = 구간 건너뛰기 (PC에서는 스페이스바, ←/→ 키)

## 파일 구성

```
서버시작.bat / 서버중지.bat / 서버상태.bat   서버 제어
server.ps1                                PowerShell 웹서버 (public 폴더 + /api/data)
public\index.html, style.css               화면
public\app.js                              타이머, 소리, 화면 제어
public\storage.js                          데이터 저장 (서버 파일 + 임시 저장)
public\schedule.js                         요일별 운동 동작
data\circuit-data.json                     설정·기록 (자동 생성)
```

포트를 바꾸려면 `서버시작.bat` 의 마지막에 `-Port 9090` 처럼 붙이면 됩니다.
